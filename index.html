    Откуда данные

    Только добровольные отчёты игроков: каждая строка реестра — реальная смерть, добавленная через форму. Сгенерированных записей здесь нет: пока отчётов мало, графики честно показывают пустоту. Проект неофициальный и не связан с GGG.

    Как считается

    Каждая запись — один павший персонаж: место, причина, источник урона, уровень, лига. Проценты пересчитываются по текущему фильтру.

    Музыка

    Плеер внизу страницы работает через официальный Spotify Embed API. Нужен аккаунт Spotify (бесплатный подойдёт), Premium — для полного трека.

    Приватность

    Пароли хешируются PBKDF2-SHA256 (120 000 итераций) на устройстве. E-mail и пароль никогда не отправляются третьим лицам.
